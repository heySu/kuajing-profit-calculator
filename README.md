# 跨境卖家利润计算器 · Cross-border Profit Calculator

基于 **Temu 核价规则** 与 **TikTok Shop 美区费率** 构建的卖家决策工具。纯前端单文件实现，零依赖，打开即用。

**在线使用**：下载 `profit-calculator.html` 双击打开即可，无需安装任何东西。

## ✨ 功能

### Tab 1 · Temu 全托管
- **核价测算**：输入 1688 拿货价、国内运费包材、退货损耗、平台核定价，实时计算单件毛利与毛利率（红 / 黄 / 绿三档判定）
- **成本结构图**：条形图直观展示核价收入被哪些成本吃掉
- **比价诊断**：根据首报价与核定价的砍幅，自动判断是否命中"全网比价"（砍幅 >50% 说明系统在站内/1688 找到了远低同款）
- **首报策略顾问**：按"期望价 × 1.15~1.2"给出建议首报区间，并根据 1688 同款价提示比价高危线
- 内置真实案例一键填入（收纳箱：报价 12.45 被核到 3.06）

### Tab 2 · TikTok 达人带货
- **单件利润测算**：售价 / 拿货+头程 / 尾程配送 / 达人佣金 / 平台佣金，实时算净利率
- **达人寄样 ROI 模型**：触达人数 × 回复率 × 寄样率 × 出单率 → 预计样品投入、出单达人数、GMV 与 ROI，自动给出"这批样品费值不值得花"的判断

### Tab 3 · 核价规则小抄
- Temu 比价系统三大锚点（1688 同源价 / 站内同款 99 折 / 终端零售倒推）
- 五大报价策略（首报锚高、成本明细议价、组合套装跳比价、改主图躲图像搜索、独家款定价权）
- TikTok Shop 美区 2026 关键数字（佣金、保证金、物流、流量来源）

## 🛠 技术实现

- 纯原生 HTML / CSS / JavaScript，单文件，无任何框架与网络请求
- 所有计算实时响应，移动端可访问

## 📌 定位

作者同时在实战跨境电商（Temu / TikTok Shop），本工具的核价规则、费率与策略均来自一线实操与公开平台规则整理——**给自己做的工具，顺便解决所有同类卖家的同一个问题**。
